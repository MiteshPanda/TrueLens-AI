🚀 Phase 2: Deepfake Detection (DAY 3–4)
Step 1: Install
pip install opencv-python torch torchvision
Step 2: Extract Frames
import cv2

def extract_frames(video_path):
    cap = cv2.VideoCapture(video_path)
    frames = []
    while True:
        ret, frame = cap.read()
        if not ret:
            break
        frames.append(frame)
    return frames
Step 3: Use Pretrained Model

👉 IMPORTANT: Don’t train from scratch

Use:

XceptionNet pretrained
Or simple CNN classifier
Step 4: Aggregate Results
prediction = sum(frame_preds) / len(frame_preds)
